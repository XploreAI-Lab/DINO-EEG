# DINO 模型评估脚本使用说明

## 脚本概述

基于训练脚本 `DINO_train_swin_tusz_multi_gpu.sh` 创建了三个评估脚本：

1. **`DINO_eval_swin_tusz_single.sh`** - 单卡评估脚本（推荐）
2. **`DINO_eval_swin_tusz_multi_gpu_fixed.sh`** - 多卡评估脚本（修复版）
3. **`DINO_eval_swin_tusz_multi_gpu.sh`** - 多卡评估脚本（原版）

## 关键区别：训练 vs 评估

### 训练过程中的验证
- 使用 **dev 数据集** 进行验证
- 目的：模型选择和超参数调优
- 生成的 `results.bbox.json` 包含 dev 数据结果

### 独立评估模式（使用 --eval 参数）
- 使用 **eval 数据集** 进行测试
- 目的：最终性能评估
- 生成的 `results.bbox.json` 包含 eval 数据结果

## 脚本使用方法

### 1. 单卡评估（推荐）

```bash
# 基本用法
bash scripts/DINO_eval_swin_tusz_single.sh /path/to/checkpoint.pth

# 示例
bash scripts/DINO_eval_swin_tusz_single.sh ./logs/checkpoint.pth
```

### 2. 多卡评估（推荐使用修复版）

```bash
# 基本用法（修复版）
bash scripts/DINO_eval_swin_tusz_multi_gpu_fixed.sh [checkpoint_path] [num_gpus]

# 使用2张GPU评估
bash scripts/DINO_eval_swin_tusz_multi_gpu_fixed.sh ./logs/checkpoint.pth 2

# 使用1张GPU评估（等同于单卡模式）
bash scripts/DINO_eval_swin_tusz_multi_gpu_fixed.sh ./logs/checkpoint.pth 1
```

## 关键参数说明

### 评估特定参数
- `--eval`: 启用评估模式，使用 eval 数据集
- `--resume`: 指定要评估的模型检查点路径
- `--save_results`: 保存详细的检测结果
- `--save_log`: 保存评估日志

### 数据路径参数（需要根据实际情况修改）
```bash
--data_dir /root/autodl-tmp/dataset_lbhdataset      # EEG数据目录
--tusz_txt_dir /root/autodl-tmp/dataset_seiztxt     # 文本文件目录
--tusz_label_dir /root/autodl-tmp/dataset_bilabel   # 标签目录
```

### 模型配置参数
```bash
-c config/DINO/DINO_4scale_swin_tusz_multi_gpu.py   # 配置文件
--options dn_scalar=100 embed_init_tgt=TRUE         # 模型选项
dn_label_coef=1.0 dn_bbox_coef=1.0 use_ema=False
```

## 输出结果

评估完成后，会在指定的输出目录中生成以下文件：

1. **`info.txt`** - 评估日志，包含详细的指标
2. **`results.bbox.json`** - 模型检测结果（eval数据集）
3. **`ground_truth.bbox.json`** - 真实标签数据
4. **`config_args_all.json`** - 完整的配置参数
5. **`log.txt`** - 训练/评估日志摘要

## 重要说明

1. **数据集区别**：
   - 训练中的验证：使用 dev 数据集
   - 独立评估：使用 eval 数据集

2. **路径配置**：
   - 请根据实际的数据存储路径修改脚本中的路径参数
   - 确保检查点文件路径正确

3. **GPU使用**：
   - 评估通常只需要1张GPU即可
   - 多卡评估主要用于大规模数据或加速处理

4. **结果解读**：
   - 关注 AP（Average Precision）指标
   - 查看 FEA、FEDA、IRA 等癫痫检测特定指标

## 故障排除

1. **CUDA设备错误（ValueError: Expected a torch.device with a specified index）**：
   - **原因**：设备参数格式问题
   - **解决**：使用修复版脚本 `DINO_eval_swin_tusz_multi_gpu_fixed.sh`
   - **或者**：在命令中明确指定 `--device cuda:0`

2. **检查点文件不存在**：
   - 确认路径正确
   - 确认文件确实存在

3. **数据路径错误**：
   - 检查数据目录是否存在
   - 确认路径权限正确

4. **GPU内存不足**：
   - 使用单卡评估
   - 减小batch size（在配置文件中修改）

5. **配置文件不匹配**：
   - 确保使用与训练时相同的配置文件
   - 检查模型架构参数是否一致

## 最近修复的问题

- **设备设置错误**：修复了 `torch.cuda.set_device(device)` 的参数类型问题
- **脚本优化**：添加了明确的设备参数 `--device cuda:0` 或 `--device cuda`
